## What this is
FED-USA News is an independent local reporting project for neighbors who need clear, useful information. It covers scam alerts, public safety, city hall, cyber incidents, and follow-ups. It is community-funded and keeps breaking scam alerts free to read.

## Quick start
1. Clone the repository.
2. Open `index.html` locally or run `make serve`.
3. Draft stories in `content/` and publish finished pages under `stories/`.
4. Review links, accessibility, and reduced-motion behavior.
5. Deploy with `npx wrangler deploy --assets=.` or GitHub Pages.

## Repo map
- `.github/` workflows, issue templates, and ownership rules
- `assets/images/` brand and social images (replace the generated placeholders)
- `brand/`, `content/`, `prompts/` editorial guidance
- `stories/`, `chapters/` published content
- `docs/` deployment and operating notes
- root HTML/CSS/JS SEO, legal, and site files
