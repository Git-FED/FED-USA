# FED-USA News Desktop

Unofficial offline Electron reader. It bundles the site under `app/site/`, never loads a live URL for content, and opens external links in the system browser. It is not affiliated with FED-OS, Patreon, Nextdoor, Cloudflare, GitHub, or any website provider.

Requires Node 20 and npm. Run `npm install`, then `npm start`. Build with `npm run dist:win`, `npm run dist:mac`, or `npm run dist:linux`. Sync the site with `npm run sync-site`.
