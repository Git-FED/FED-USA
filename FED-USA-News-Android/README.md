# FED-USA News Android

Unofficial offline reader wrapper. It loads the bundled `app/src/main/assets/site/index.html` and hands external links to the system browser. It is not affiliated with Patreon, Nextdoor, Cloudflare, GitHub, or any website provider.

Build with `./gradlew assembleDebug` after adding a standard Gradle wrapper. Replace the bundled site after each site release and inspect the diff.
