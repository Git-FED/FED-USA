# Deploy

1. Replace placeholder images and email addresses.
2. Choose a newsletter provider and update the homepage form.
3. Set your domain and update canonical URLs, sitemap, and redirects.
4. Run `python3 -m http.server 8080` and test mobile, keyboard, and reduced motion.
5. Deploy with `npx wrangler deploy --assets=.` or enable GitHub Pages.

The long Patreon checkout URL supplied during planning is not used; use the stable public campaign URL instead.
