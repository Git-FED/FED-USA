# Contributing

Writers, tipsters, editors, designers, and accessibility contributors are welcome.

## Submit a story
Fork the repo, create `story/your-slug`, draft in `content/` using `content/voice-guide.md`, verify every factual claim, and open a pull request.

## Submit a tip
Do not open a public issue for a sensitive tip. Email `tips@fed-usa.news` and ask about a safer channel when appropriate.

## Voice and style
Use third person, lead with the local hook, include a byline sign-off, avoid hype adjectives, and name the source in the first paragraph.

## We do not publish
Unverified rumors, doxxing, private addresses, unfounded accusations, or AI-generated fake quotes.

## PR checklist
- [ ] Voice guide followed
- [ ] No broken links
- [ ] Tested in a browser
- [ ] Images optimized
- [ ] No secrets committed
